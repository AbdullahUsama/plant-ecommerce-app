# Plant E-Commerce Application 🌱

Recently, I developed a **simple E-commerce website** for plants and related products. This project includes several powerful functionalities and features that make it both robust and user-friendly.

---

## Features and Functionalities

1. **Role-Based Authentication and Authorization**:  
   Integrated with [Clerk.com](https://clerk.dev) for seamless user authentication and role-based access control.
   
2. **Language Preferences**:  
   Utilizes **React-i18n** for multi-language support (Urdu/English).

3. **Payment Integration**:  
   Integrated **Stripe** for secure and reliable checkout and payment processing.

4. **Frontend**:  
   Built using **React.js** for a dynamic and responsive user interface.

5. **Database**:  
   Stores product data in a scalable **MongoDB** NoSQL database.

6. **Backend**:  
   Powered by **Node.js** and **Express.js** for API development and server-side logic.

---

## Additional Features

- **Product Category Filtering**:  
  Allows users to filter products based on categories.
  
- **Dark Mode**:  
  Supports a toggle for light/dark mode to enhance user experience.

- **Admin Panel**:  
  A dedicated admin interface for managing products and orders.

- **CRUD Functionality**:  
  Simple Create, Read, Update, and Delete operations for product management.

---

## Tech Stack

| **Technology**       | **Purpose**                      |
|-----------------------|----------------------------------|
| React.js              | Frontend Development            |
| React-i18n            | Language Localization           |
| Clerk.com             | Authentication & Authorization  |
| Stripe                | Payment Gateway Integration     |
| MongoDB               | Database                        |
| Node.js & Express.js  | Backend and REST API            |
